Règles d’exemptions et nombre de postes

Document basé sur les règles techniques Offibox (licences et appareils).

1. Règle appliquée partout (desktop + version en ligne)

  • La limite est gérée côté Cloud Function registerDevice (Firebase).
  • Les comptes suivants sont exemptés de la limite (équivalent 999 postes), que ce soit depuis l’app desktop ou la version en ligne :
    • contact@offibox.fr
    • offibox@offibox.fr
    • offibox@gmail.com
    • offibox17@gmail.com

2. Nombre de postes par compte

Le nombre max de postes par compte est défini dans Firestore :

Collection : users

Document : users/{uid} (uid = identifiant Firebase Auth du compte)

Champ : maxDevices (nombre, optionnel)

Comportement :

  • Si maxDevices est absent → limite par défaut = 5 postes.
  • Si vous mettez maxDevices: 10 (ou autre) sur un document users/{uid} → ce compte pourra enregistrer jusqu’à 10 appareils.

Où modifier :

  1. Console Firebase — Firestore Database → collection users → document correspondant à l’email (uid) → ajouter ou modifier le champ maxDevices.
  2. Tableau de bord admin (futur) — Écran réservé à offibox17@gmail.com / offibox@gmail.com pour éditer maxDevices par client.
  3. Script ou Cloud Function — Mise à jour de users/{uid}.maxDevices (ex. à l’activation d’une licence ou depuis un back-office).

En résumé : un email = un uid = un document users/{uid} ; le champ maxDevices contrôle le nombre de postes autorisés pour ce compte.

3. Connexion depuis plusieurs endroits / partage d’identifiants

  • Chaque poste (PC, machine) est identifié par un deviceId unique. À chaque connexion avec le même compte, l’app enregistre cet appareil via registerDevice.
  • La limite (ex. 5) s’applique au nombre d’appareils distincts enregistrés pour ce compte, pas au nombre de connexions simultanées.

En pratique :

  • Même personne, plusieurs PC : chaque PC = 1 appareil. 5 PC différents = 5 postes, 6ᵉ PC = blocage « limite de 5 postes » (sauf si maxDevices a été augmenté pour ce compte).
  • Partage d’identifiant / mot de passe : si quelqu’un d’autre se connecte avec le même email/mot de passe, son PC compte comme un nouvel appareil. Partager ses identifiants = remplir les postes plus vite (voire bloquer le titulaire si 5 postes sont déjà enregistrés).

Il n’y a pas de détection du « partage » : on compte uniquement les appareils différents. Pour limiter le partage : garder la limite à 5 (ou moins) et communiquer « 5 postes max par compte », ou augmenter maxDevices pour certains contrats dans Firestore.

4. Résumé

Question Réponse
Même règle desktop + version en ligne ? Oui. La Cloud Function registerDevice est la même ; les emails exemptés ont 999 postes partout.
Où contrôler le nombre de licences par email ? Firestore users/{uid}.maxDevices (par défaut 5 si absent). Modifiable dans la console Firebase ou via un écran admin.
Plusieurs connexions / partage de compte ? On compte les appareils (postes) différents. Partager identifiant + mot de passe = chaque PC compte comme 1 poste.
