Offibox — Architecture technique et sources externes

Document de présentation pour développeurs — Généré le 15 mars 2026

1. Stack technique

CoucheTechnologie
FrameworkFlutter (Dart 3.3+)
Plateforme cibleDesktop Windows (prioritaire), Linux en cours, iOS/Android prévu
State managementRiverpod + Provider
Backend / AuthFirebase (Auth, Firestore, Storage, Functions)
Cache localHive
UIMaterial Design, Google Fonts (Spinnaker)

2. Structure du projet

lib/
├── app/                    # Point d'entrée, MaterialApp, thème
├── auth/                   # Firebase Auth, login, protocole offibox://
├── config/                 # AppConfig, OAuth Google
├── constants/              # UI (couleurs, dimensions)
├── controllers/            # OffiboxController (logique principale)
├── core/                   # Filtres de recherche
├── data/                   # Parsers, loaders, sources de données
├── models/                 # SearchResult, SourceType, ClientProfile (freezed)
├── providers/              # Riverpod providers
├── search/                 # SearchEngine (moteur de recherche)
├── services/               # Annuaire PS, ANSM, PDF, etc.
├── system/                 # Fenêtre, autostart Windows
├── ui/                     # Widgets, écrans, résultats
├── utils/                  # Normalisation, open_url, scan
└── window/                 # Fenêtre frameless, barre flottante

3. Flux de données

[CSV GitHub offiboxdata] + [APIs externes] → DataLoaderCore → OffiboxController → SearchEngine (indexation) → Recherche utilisateur → Affichage résultats

5. Points clés pour un développeur

  • OffiboxController (~1300 lignes) : logique centrale, chargement, recherche, filtres
  • SearchEngine : recherche synchrone, index par préfixe, cache, typo-tolérance
  • data_sources.dart : URLs des CSV
  • Parsers : bdm_parser, keywords_parser, lpp_loader, etc.
  • Riverpod : offiboxControllerProvider, clientProfileProvider
  • Plateforme : Platform.isWindows / Platform.isLinux
  • Secrets : OFFIBOXDATA_GITHUB_TOKEN, ESANTE_API_KEY (--dart-define)
