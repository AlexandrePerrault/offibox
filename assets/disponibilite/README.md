# Image « disponibilité produits - semaine 13 »

Pour que le badge « disponibilité produits » (ligne 2 catalogue Viatris) affiche l’image sous la barre :

1. Copiez votre fichier (ex. `Sans titre.jpg` depuis Téléchargements) dans ce dossier.
2. Renommez-le en : **disponibilite_semaine13.jpg**

L’app affichera le titre « disponibilité produits - semaine 13 » et l’image en dessous.
