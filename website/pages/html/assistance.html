Assistance à distance – Offibox

Un technicien Offibox peut installer ou configurer le logiciel sur votre poste, uniquement avec votre accord, pendant une session guidée.

Lancer l’assistance

Pendant un rendez-vous téléphonique ou par e-mail avec Offibox, ouvrez cette page et cliquez sur le bouton ci-dessous. Un petit outil d’assistance se télécharge : acceptez-le, puis communiquez le code affiché à votre interlocuteur.

Télécharger l’outil d’assistance

Windows uniquement · session ponctuelle · aucune installation permanente obligatoire

L’accès s’arrête dès que vous fermez la session. Aucune prise en main n’est possible sans votre validation à l’écran.

Comment ça se passe ?

  1. Prenez rendez-vous avec Offibox (contact@offibox.fr ou par téléphone.
  2. Cliquez sur Télécharger l’outil d’assistance et lancez le fichier.
  3. Communiquez le code affiché à votre technicien Offibox.
  4. Acceptez la demande de prise en main lorsqu’elle apparaît à l’écran.
  5. Le technicien installe / configure Offibox (clé API, WebView2 si besoin), puis vous refermez la session ensemble.

Avant de commencer

  • Être devant le PC Windows de l’officine
  • Disposer d’un accès administrateur (ou d’une personne habilité)
  • Avoir votre clé Offibox sous la main (reçue à l’inscription)
  • Autoriser temporairement le téléchargement si l’antivirus le demande
  • Prévoir 10 à 20 minutes selon la connexion

Ce que nous pouvons faire pendant la session

  • Installer ou mettre à jour Offibox
  • Saisir / vérifier la clé de première connexion
  • Vérifier WebView2, le démarrage Windows, les mises à jour
  • Vous montrer les gestes essentiels (pilule, recherche, Mon compte)

Confidentialité

La session est destinée uniquement à l’assistance technique Offibox. Fermez les logiciels contenant des données patients avant de démarrer si vous le souhaitez. Vous pouvez couper la session à tout moment.
