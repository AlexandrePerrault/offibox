Ce que vous pouvez scanner

DataMatrix boîte médicament

Offibox lit automatiquement :

  • CIP
  • Date d'expiration
  • Numéro de lot
  • Numéro de série

QR mutuelle

Le code mutuelle est reconnu et la fiche correspondante s'affiche directement.

QR d'ordonnance / téléconsultation

Medadom, Qare et autres liens sont ouverts dans la fenêtre web intégrée Offibox.

Code RPPS

Recherche inverse : vous saisissez le RPPS, Offibox retrouve le professionnel.

Ce que vous trouvez dans Offibox

Médicaments

Nom, CIP, DCI, disponibilité, statut, remboursement, alertes et liens utiles.

Annuaire santé

Professionnels de santé, structures, recherche par nom, ville, RPPS.

Mutuelles et organismes

Recherche par nom, code, contact, informations de prise en charge.

Documents et contenus

PDF, vidéos, pages web, informations laboratoires, outils métier.

Un usage simple au comptoir

1. Vous scannez un code (boîte, mutuelle, ordonnance).
2. Offibox retrouve l'information utile immédiatement.
3. Vous ouvrez les documents/liens sans quitter l'application.
4. Vous gagnez du temps, avec moins de manipulations.
Télécharger Offibox
